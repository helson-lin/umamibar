## 范围和视觉

本轮覆盖登录时启动、网站排序与置顶、菜单栏数字配置、最近成功数据持久化。沿用现有 AppKit 系统字体、360pt 概览浮窗、440pt 设置窗口、灰色玻璃表面和每站固定图表色。设置窗口设计基准增加到 640pt 高；小屏时限制到可用高度，内部内容滚动，分类与底部状态固定。

设置继续使用「连接 / 网站 / 通用」三级分类，不新增顶层页面。

| 位置 | 新增内容 |
| --- | --- |
| 通用 | 登录时启动、菜单栏显示、本地数据 |
| 网站 | 置顶组、普通组、未选择组、拖动和键盘排序 |
| 概览 | 置顶标识、跟随设置的展示顺序、本地数据提示、无保存记录状态 |
| 菜单栏 | 合计／指定网站／仅图标，以及本地数据来源提示 |

本轮设计将网站管理与偏好变更即时保存，并即时更新概览；连接凭据仍沿用验证成功后应用的现有流程。此处是下一版拟采用的交互行为，不代表当前原生程序已支持。

## 1. 登录时启动

- 默认关闭，位置在「通用」顶部。
- 开启后，登录 macOS 时静默进入菜单栏，不自动展开概览或设置。
- 开关反映系统实际允许状态。被系统停用时显示关闭状态和说明，提供「前往系统设置开启」。不能在界面上假装重新启用成功。
- 注册失败时恢复原状态，保留错误说明及重试；不得只保存一个与系统脱节的偏好值。
- 设计稿提供「启动被系统停用」场景。入口与文案在原生实现时按系统版本适配；现有最低 macOS 版本承诺保持有效，旧版本采用相应可用方式。

## 2. 网站排序与置顶

- 默认沿用现有网站顺序，不自动置顶。设计稿初始置顶 Fanbar，供评审观察效果。
- 已选网站分为「置顶」和「其他网站」，未关注的网站放在「未选择」。概览只显示已选网站。
- 点击图钉将网站加入置顶组末尾；取消置顶时恢复其普通列表的手动顺序。
- 两组分别维护顺序。拖动仅调整组内排序，不通过跨组拖动隐式改变置顶状态。
- 每行提供可聚焦的上移／下移按钮；鼠标悬停或键盘聚焦时显示，首尾边界禁用对应方向。
- 搜索期间保留筛选、关注和置顶能力，禁用排序，避免用户在不完整列表中误判位置。
- 刷新、时间范围切换、重启后顺序不变。新发现的网站追加到普通列表末尾，不打乱手动顺序。
- 临时取消关注保留该网站的排序与置顶偏好，重新关注时恢复。服务端确认网站已删除或连接已切换时清理失效引用。
- 取消所有关注后，概览显示「选择你关注的网站」，提供网站设置入口；不将无数据当成 0。

## 3. 菜单栏数字配置

| 模式 | 数字含义 | 默认 |
| --- | --- | --- |
| 合计访客 | 已选网站在当前概览时间范围内的访客数相加，跨站未去重 | 是 |
| 指定网站 | 从已关注网站选择一个，显示该站的访客数 | 否 |
| 仅图标 | 隐藏数字，保留点击入口 | 否 |

- 仅图标采用系统标准方形宽度，显示数字时随内容自适应；浮窗始终锚定当前菜单栏按钮。数字继续使用现有紧凑格式。
- 指定网站模式下才显示「数字来源」选择器。无关注网站时禁用此模式。
- 来源网站被取消关注／删除：回退「合计访客」并明确提示；不能静默指向另一个网站。
- 提示文字提供网站／汇总口径、时间范围、精确数字。离线数值增加「本地数据、成功时间」；界面增加微小状态点，辅助用户发现来源变化，文字仍为主要语义。
- 成功且零访问显示 0。无成功数据或汇总缺少任一站的数据时显示「—」，不能将不完整小计当成全部访客。
- 指定网站模式只取该站状态，不因其他网站失败而丢失该站可用数字。
- 冷启动先展示同一范围的本地数据，并后台刷新；刷新失败则保留本地数值和时间标记。

## 4. 最近成功数据

- 默认开启，位置在「通用 → 本地数据」。
- 每个连接、网站、时间范围分别保存最近一次成功结果，包括统计、趋势、比较数据、实际查询起止时间与各部分成功时间。不同成功批次不得伪装为同一查询结果。
- 概览摘要展示最近保存时间和网站数；「查看保存范围」展开各时间范围及其查询区间。
- 冷启动显示保存结果时立即注明本地来源，后台尝试刷新。在线成功结果替换同范围保存记录；失败不覆盖成功记录。
- 离线状态使用浅琥珀提示：「当前离线 · 显示上次成功数据」，并显示成功时间。查询起止时间保留保存记录里的值，不随当前时间向前滚动。
- 单站结果缺失时该站显示「—」和「该范围暂无已保存数据」，其余网站仍可显示；整范围无记录时展示清楚的空状态与重试入口。
- 从未获取成功的首次离线状态单独展示「还没有成功获取过数据」。
- 「清除已保存数据…」使用就地二次确认：仅清除持久化统计数据，保留连接、钥匙串密钥、网站选择、顺序与偏好。当前已显示的在线数据可以继续查看，下次成功刷新可重新保存。
- 关闭保存开关需确认「关闭并清除」，清除已有持久化统计数据并停止后续保存。重新开启仅对下次成功请求生效，不伪造保存记录。
- 保存失败时在线结果仍可用；设置中说明「未能保存」，提供重试，避免错误地宣称已保存。
- 连接变更隔离不同服务的数据；断开连接时清除该连接下数据。API Key 始终只存于钥匙串。
- 详情数据只有同一连接／网站／范围／维度的成功记录才可恢复；未保存的维度离线时显示不可用。不能借用其他维度结果。

## 原型边界

原型可操作网站关注、组内排序、置顶、数字模式、时间范围、保存开关、清除确认与场景切换。拖动与键盘按钮共用排序规则。偏好以浏览器本地存储保存，原生实现不使用该存储方式。

演示数据固定为 10 月 18 日 14:43:50，初始拥有「最近 24 小时」「最近 7 天」记录，「最近一个月」无记录，便于检查空状态。场景切换仅模拟网络与系统状态。语言、更新和连接入口沿用现有功能，本轮仅展示位置；原型不操作系统登录项或真实凭据。

此说明包含注册失败、保存失败和单维度缺失等原生实现验收约束；演示场景并未逐一模拟所有底层错误。

## 布局与排版修订 02

本轮仅调整设计稿布局和排版，保留四项需求与现有交互。

- 设置窗口采用紧凑的居中标题与 256pt 分类控件，移除重复的品牌图标与副标题，为设置正文释放空间。
- 统一 24pt 内容边距和右侧控件轴线；分组使用 16pt 纵向间距，说明紧随对应设置。
- 系统字体按角色集中管理：正文 13pt、次级文字 12pt、说明 11pt；概览标题 14pt、主数字 24pt。日期和坐标为 10pt，数值使用等宽数字。
- 菜单栏显示合并重复标题；保存时间与范围入口合为一行，隐私说明和清除操作分列，减少纵向堆叠。
- 网站列表固定名称、域名、图钉与排序按钮列；基准行高 52pt。常规四站列表及提示在窗口内完整呈现，扩展内容保持内部滚动。
- 概览卡片调整为约 200pt，保留指标与图表，使两站的完整指标在正常状态下同时可见。
- 设计说明默认折叠，预览场景控件位于窗口外，减少评审画布中的次要信息干扰。
- 浅深两套颜色同步提高说明文字对比度；窄屏下保持纵向排列与可访问的操作入口。


## 设置页结构修订 03

针对设置页仍显零散的反馈，通用页统一为三组原生列表式表单：

- **常规**：登录时启动、语言。
- **菜单栏**：显示内容、指定网站（按需出现）。显示内容改用下拉选择，与其他选择控件保持同一宽度和对齐线。
- **本地数据**：保留开关、已保存数据入口。默认只展示保存摘要；点击摘要后再展开范围与清除操作，确认流程保留。

每组使用相同的 44pt 行高、左侧标签和右侧控件。辅助说明统一放在组下方。取消混用的分段按钮、独立状态条和散落的文字操作，概览及网站管理交互保持原样。

设置页近景：[浅色](settings-layout-v3-light.png) · [深色](settings-layout-v3-dark.png)。


## 网站页修订 04 与原生实现

搜索框、关注计数和批量操作固定在列表上方。置顶、其他网站、未关注采用与通用页一致的分组容器；名称与域名共列，颜色并入名称旁，置顶、方向按钮与拖动把手集中在行尾。搜索无结果时提供清空入口，搜索期间暂停排序。原生设置页使用同一结构，支持即时保存与键盘焦点恢复。

原生实现的验证与功能边界见 PRD 第 17 节和主 README；本 HTML 仍然只使用演示数据，不操作系统设置或真实连接。
